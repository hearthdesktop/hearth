# Contributing to Hearth

Issues and pull requests are welcome.

## Reporting bugs and requesting features

Open an issue with one of the templates, or a blank one if neither fits. Problems with a Vencord plugin belong in
[Vencord's repository](https://github.com/Vendicated/Vencord), since plugins come from Vencord.

## Pull requests

- Keep each pull request to one change, and explain what it does and why.
- Test it yourself before opening the pull request, and say how you tested it.
- Make sure `pnpm test` (lint and typecheck) passes.

## AI-assisted contributions

Using AI tools while writing code is fine, as long as you take responsibility for the result:

- Review every line by hand before submitting, and be ready to explain and defend it in review.
- Test the changes yourself. An AI saying it works is not testing.
- Write the pull request description and your review replies yourself. Pull requests opened by autonomous agents, or
  with generated descriptions, will be closed.
